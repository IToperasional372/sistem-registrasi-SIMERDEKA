Akses Kamera Dibatasi!

Browser HP Anda membatasi akses kamera karena masalah protokol keamanan (non-HTTPS) atau izin yang tidak sengaja terblokir.

Pastikan URL dibuka melalui HTTPS:

Pengguna Android (Google Chrome):

  1. Ketuk ikon Gembok / Setelan di kiri kolom alamat URL browser Anda.
  2. Pilih menu Izin (Permissions) atau Setelan Situs (Site Settings).
  3. Aktifkan sakelar Kamera ke posisi **Izinkan / Allow**.
  4. Muat ulang (*Refresh*) halaman dashboard Anda.

Pengguna iPhone/iPad (Safari):

  1. Buka menu Pengaturan (Settings) utama pada perangkat Apple Anda.
  2. Gulir ke bawah and ketuk aplikasi **Safari**.
  3. Di bawah bagian *Setelan Situs Web*, pilih **Kamera**.
  4. Ubah pilihan dari *Tanya* atau *Minta* menjadi **Izinkan (Allow)**.
  5. Kembali ke Safari and muat ulang halaman dashboard Anda.

Akses API Google Terkunci!

Sistem mendeteksi kegagalan komunikasi dengan Google Sheets. Hal ini umumnya terjadi karena setelan keamanan Web App di Google Apps Script Anda masih dikunci sebagai Only myself (Hanya Saya).

🛠️ Cara Membuka Akses (Wajib):

  1. Buka editor Google Apps Script proyek Anda.
  2. Klik tombol biru Deploy (Terapkan) di pojok kanan atas.
  3. Pilih Manage deployments (Kelola penerapan).
  4. Klik ikon Pensil (Edit) pada versi aktif Anda saat ini.
  5. Ubah setelan Who has access (Siapa yang memiliki akses) dari Only myself menjadi Anyone (Siapa saja).
  6. Klik tombol Deploy untuk menerapkan versi baru tersebut.
